YouTube Video Factory

Start Here

This repo turns a production brief, references, prompt drafts, and optional provider keys into a narrated HyperFrames YouTube video project.

Read the workflow See layouts and palettes Codex skill

Create a project folder

From this repo folder, a simple project name creates a new subfolder under projects/.

pnpm install
pnpm ytvf init my-video --title "My Video"
pnpm ytvf brief projects/my-video

Where your project files go

Each video project gets its own folder, for example projects/my-video/. That folder contains the brief, uploaded references, prompt drafts, generated media, provider records, previews, validation artifacts, and final output.

What to do in Codex

Open this repo in the Codex app and say: Use the YouTube Video Factory skill. Create a video project from my brief.
